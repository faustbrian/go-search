# Security policy

Report vulnerabilities through a private
[GitHub security advisory](https://github.com/faustbrian/go-search/security/advisories/new).
Include the affected version, a minimal reproducer, the expected security
boundary, and the observed impact. Do not include credentials, document
sources, queries, signed cursors, PIT IDs, backend bodies, or tenant data in a
public issue. Supported releases receive security fixes; unreleased revisions
are not a support commitment.
